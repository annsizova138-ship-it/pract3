# УВМ: ассемблер и интерпретатор (вариант 20)

## 1. Общее описание

Ассемблер и интерпретатор учебной виртуальной машины (УВМ). Ассемблер переводит программу на языке ассемблера в машинный код, интерпретатор выполняет машинный код и сохраняет дамп памяти в формате CSV. Программы написаны на Python, используется только стандартная библиотека.

Выполнены этапы 1-3: добавлен интерпретатор с единой памятью и дампом памяти в формате CSV.

## 2. Описание всех функций и настроек

### Архитектура УВМ

Учебная виртуальная машина имеет регистр-аккумулятор `acc` (в начале работы равен 0) и **одну память для команд и данных**. Каждая команда занимает **5 байт** (40 бит). Поле A (биты 0-7) - код операции, поле B (биты 8 и выше) - операнд.

| Операция | A | Поле B | Действие |
|---|---|---|---|
| Загрузка константы | 44 | биты 8-38 (константа, 31 бит) | `acc = B` |
| Чтение из памяти | 223 | биты 8-32 (адрес, 25 бит) | `acc = mem[B]` |
| Запись в память | 174 | биты 8-32 (адрес, 25 бит) | `mem[B] = acc` |

Бинарная операция `max()` (A=169) появится на этапе 4.

**Машинный код.** Команда записывается как число `A + B * 256` в 5 байтах, **младший байт первым** (little-endian). Например, команда A=44, B=260 превращается в байты `0x2C, 0x04, 0x01, 0x00, 0x00`.

**Память.** Адреса - целые числа от 0 до 33554431 (25 бит), ячейка хранит целое число. Память одна для команд и данных: программа загружается с адреса 0, каждый байт программы занимает отдельную ячейку. Данные нужно размещать по адресам **после области команд** (в примерах - начиная с адреса 200). Ячейка, в которую ничего не писали, содержит 0. Значения целые неотрицательные (константа - от 0 до 2147483647).

**Выполнение.** Интерпретатор читает из памяти 5 байт по адресу счётчика команд, переводит их в поля A и B, выполняет команду и переходит к следующей. Работа заканчивается, когда счётчик выходит за область программы.

### Язык ассемблера

Один оператор на строку, "алгебраический" синтаксис:

| Строка | Команда |
|---|---|
| `acc = 260` | загрузка константы (A=44) |
| `acc = mem[574]` | чтение из памяти (A=223) |
| `mem[152] = acc` | запись в память (A=174) |

Числа можно писать в десятичном (`260`), шестнадцатеричном (`0x104`) и двоичном (`0b101`) виде. Пробелы свободные. Комментарий начинается с `#`, пустые строки пропускаются.

Строка `acc = max(acc, mem[N])` распознаётся ассемблером, но выполнять её интерпретатор начнёт на этапе 4.

### Ассемблер

```
python src/assembler.py --source ФАЙЛ --output ФАЙЛ [--test]
```

| Параметр | Описание |
|---|---|
| `--source ФАЙЛ` | исходный файл с программой на языке ассемблера (обязательный) |
| `--output ФАЙЛ` | двоичный файл-результат (обязательный) |
| `--test` | режим тестирования: вывести результат ассемблирования на экран в байтовом формате (одна команда в строке) |

После работы выводится размер двоичного файла в байтах.

### Интерпретатор

```
python src/interpreter.py --binary ФАЙЛ --dump ФАЙЛ --range НАЧАЛО КОНЕЦ
```

| Параметр | Описание |
|---|---|
| `--binary ФАЙЛ` | двоичный файл с программой (обязательный) |
| `--dump ФАЙЛ` | файл, в который сохраняется дамп памяти (обязательный) |
| `--range НАЧАЛО КОНЕЦ` | диапазон адресов дампа, **включая оба конца**; адреса можно писать как `200` или `0xC8` (обязательный) |

Дамп сохраняется в формате **CSV**: первая строка `address,value`, затем по строке `адрес,значение` на каждую ячейку диапазона. Тот же текст выводится на экран.

### Обработка ошибок

Ошибки параметров (не задан или неверный параметр, нет файла, неверный диапазон) выводятся как `Ошибка параметров: ...`, программа завершается с кодом 2. Ошибки работы (синтаксическая ошибка в программе с номером строки, значение вне диапазона поля B, неизвестная команда, размер программы не кратен 5, адрес вне памяти) выводятся как `Ошибка: ...`, код 1. Успех - код 0.

### Файлы проекта

```
src/        исходный код: assembler.py, interpreter.py (командная строка),
            syntax.py (язык ассемблера), encoding.py (машинный код),
            memory.py, machine.py (виртуальная машина) и вспомогательные модули
tests/      модульные тесты (unittest)
examples/   программы на языке ассемблера
scripts/    скрипты Windows (.bat): запуск тестов и демонстрации
run.bat     запуск ассемблера, run_vm.bat - запуск интерпретатора
```

## 3. Команды для сборки проекта и запуска тестов

Сборка не требуется: нужен Python 3 (разработано на версии 3.10), сторонние библиотеки не используются.

Запуск тестов (из корня репозитория):

```
# Windows
scripts\run_tests.bat

# Linux / macOS / Git Bash
PYTHONPATH=src python3 -m unittest discover tests
```

Запуск программ (папка `output` создаётся заранее, git её игнорирует):

```
mkdir output
python src/assembler.py --source examples/copy_array.asm --output output/copy_array.bin
python src/interpreter.py --binary output/copy_array.bin --dump output/copy_array.csv --range 200 214
```

Демонстрации (Windows): `scripts\demo_stage1.bat` ... `scripts\demo_stage3.bat`. Двоичные файлы создаются в папке `output` и в репозиторий не попадают.

## 4. Примеры использования

Тесты из спецификации УВМ (`examples/spec_tests.asm`), режим тестирования. Байты совпадают со спецификацией:

```
# Тесты из спецификации УВМ (вариант 20)
acc = 260          # загрузка константы: A=44, B=260
acc = mem[574]     # чтение из памяти:   A=223, B=574
mem[152] = acc     # запись в память:    A=174, B=152
acc = max(acc, mem[113])   # max():      A=169, B=113
```

```
python src/assembler.py --source examples/spec_tests.asm --output output/spec_tests.bin --test
```
